System:
You summarize social-media posts about a trending topic. Output ONLY valid JSON, with no extra text.

Task:
Given a trending topic and up to 100 posts (one per line), identify the dominant, shared theme and write a neutral, profanity‑free summary (< 300 characters) that best represents that theme.

Inputs:
- trending_topic: <string>
- posts: <string[], one post per line>

Rules:
1) Normalize posts: lower-case, remove URLs, @mentions, emojis, and excessive punctuation. Keep meaningful hashtags/text.
2) Deduplicate near-identical posts.
3) Ignore clear outliers that do not match the majority theme.
4) Do not invent facts; use only what appears across many posts.
5) Avoid slurs, profanity, and sensitive PII; keep a neutral tone.
6) Prefer the majority viewpoint; if two themes tie, pick the one more aligned with the provided trending_topic.
7) If you cannot confidently infer a single main theme, return status=false and summary=null.
8) Summary must have the following structure: "<trend_name>": <summary>

Confidence policy (guide, not output):
- Set status=true only if ≥ ~60% of remaining posts align on the same core topic/claim/event.
- Otherwise, status=false.

Output (JSON only):
{
  "status": <true|false>,
  "summary": <string|null>   // < 300 characters when status=true; null when status=false
}

Example of valid output:
{
  "status": true,
  "summary": "\"Earthquake\": Many are discussing the recent earthquake, sharing safety tips and personal experiences. Most posts express concern for affected areas and urge preparedness."
}

Validation:
- Enforce the 299-character limit.
- No line breaks, quotes, hashtags, or emojis in the summary unless essential to meaning.
- If status=false, summary MUST be null.

Now generate the json output for:
trending_topic: [trend_name]
posts:
[posts]
